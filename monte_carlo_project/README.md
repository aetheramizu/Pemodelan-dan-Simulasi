# Proyek Monte Carlo Simulation

## Isi Folder

- `problem3_risk_analysis.py` — kode Problem 3
- `problem5_portfolio_optimization.py` — kode Problem 5
- `REPORT.md` — draft laporan lengkap
- `hasil_problem3_bahasa_indonesia.csv` — hasil simulasi Problem 3
- `hasil_problem5_portfolio_bahasa_indonesia.csv` — hasil portfolio Problem 5
- `hasil_problem5_return_bahasa_indonesia.csv` — hasil simulasi return satu tahun
- `figures/` — visualisasi
- `requirements.txt` — library Python

## Instalasi

```bash
pip install -r requirements.txt
```

Kode dapat dijalankan di Google Colab, Jupyter Notebook, maupun Python lokal.

## Catatan

Parameter aset pada Problem 5 adalah data sintetis untuk tujuan akademik dan bukan data historis pasar aktual.
